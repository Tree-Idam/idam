# 아이담 카페 홈페이지 V3

첨부해 주신 사진 4장과 영상 1개를 반영한 GitHub Pages용 정적 홈페이지입니다.

## 배포 방법
1. ZIP 압축을 풉니다.
2. `tree-idam/idam` GitHub 저장소의 최상위에 `index.html`, `style.css`, `script.js`, `assets` 폴더를 그대로 업로드합니다.
3. 기존 동일 이름 파일은 교체하고 변경사항을 커밋합니다.
4. GitHub Pages 배포 후 https://tree-idam.github.io/idam/ 에서 확인합니다.
5. 기존 페이지가 보이면 강력 새로고침(Ctrl+Shift+R)을 해 보세요.

**주의:** `assets/idam-video.mp4`를 반드시 함께 올려야 메인 영상이 재생됩니다. 파일명과 폴더 구조를 변경하지 마세요.

## 콘텐츠 수정
- `index.html`에서 운영시간, 연락처, 메뉴, 이용 수칙, 주소를 수정합니다.
- `style.css`에서 색상과 배치를 수정합니다.
- `assets` 폴더에 사진·영상이 있습니다.
- 영상 자동 재생은 브라우저 설정 및 절전 정책에 따라 제한될 수 있습니다. 재생 실패 시 배경 사진이 표시됩니다.
- 이미지들은 웹 최적화를 위해 WebP로 변환했습니다.

## 게시 전 확인
- 영업시간은 월·화·수·토 12:00–22:00만 이전 대화에서 확인된 공개 정보로 반영했습니다. 다른 요일은 미확인입니다.
- 메뉴 가격, 반려동물 정책, 주차 및 전화번호는 변경될 수 있으므로 실제 매장 정책과 대조해 주세요.
- 공간 사진은 제공된 사진의 외관과 실내를 기반으로 분류했으며, 공간별 정확한 층수는 확정 표기하지 않았습니다.
- 첨부 사진 및 영상의 웹 게시 권한을 확인해 주세요.
